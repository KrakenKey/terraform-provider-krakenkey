# KrakenKey Provider

The KrakenKey provider manages [KrakenKey](https://krakenkey.io) domains, Let's Encrypt certificates issued through ACME DNS-01, TLS endpoint monitoring and alert channels.

KrakenKey never generates or stores private keys. `krakenkey_certificate` takes a CSR, so the private key stays wherever you create it. With Terraform 1.11 or later you can create the key as an ephemeral resource and pass it to a secret store through a write-only argument, so it never reaches state; see the [design notes](https://github.com/KrakenKey/terraform-provider-krakenkey/blob/main/DESIGN.md#private-keys).

## Authentication

The provider uses a KrakenKey API key (`kk_...`), the same kind of key the [CLI](https://github.com/KrakenKey/cli) uses. Create one in the dashboard and set `KK_API_KEY`, or set `api_key` in the provider block. A key limited to certain scopes needs the scopes for the resources it manages, for example `certs:issue` to create certificates.

## Example Usage

```terraform
terraform {
  required_providers {
    krakenkey = {
      source  = "krakenkey/krakenkey"
      version = "~> 0.1"
    }
  }
}

# Reads the API key from KK_API_KEY when api_key is not set.
provider "krakenkey" {}
```
